## What is intentionally not published

CADMEA's original source belongs to a collaborative project with external stakeholders. The public repository therefore contains **no proprietary API logic, partner datasets, private credentials, database records, deployment scripts or jointly owned application source**.

The diagrams are authored anew from the observed behavior and synthetic test facts. They are **explanatory figures**, not claimed screenshots of the currently deployed site.

The archived recording and genuine UI stills were reviewed separately. Publication rights for those original team-owned images/video are not independently confirmed here, so they are not silently pushed into the public repository.

The public GitHub repository is a **retrospective engineering case study**. Its commit timestamps reflect when the documentation was made, not the 2026 hackathon build or the private code history.
